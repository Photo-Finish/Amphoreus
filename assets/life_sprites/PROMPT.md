# Life-sprite prompt lock (2D Amphoreus)

Do **not** feed `assets/galgame/*.jpg` as style references. Those are 3D
in-game stills and pull the generator into CGI.

## Required style (every generate)

- 2D hand-painted illustration only (HSR Amphoreus splash / concept art)
- Hellenistic marble + antique gold + sage olive
- Isolated sprite, matte `#1a1524` ground, no scenery, no text

## Forbidden

- 3D render / CGI / Blender / Unreal / plastic shader / photoreal / Pixar
- Game screenshot as the *style*
- Japanese torii / Shinto shrine / Xianzhou / Penacony
- Classical lion–goat–snake chimera
- Mermaid (siren is song, not a figure)
- Named Chrysos Heirs
- Human hands / arms / sleeves in pet films (reaction pose only; no petting hand)

## On-stage (land UI)

Painted PNGs are only for **outdoor interactive** figures (chimera, dromas,
square cat, civilian, well, stall, forge, gate, boat, kite, olive, cicada…).
Indoor furniture (bath, hearth, lamp, scroll, loom) is not staged.
Ambient grass / wind / wheat / dawn is CSS or SVG, not a painted sprite.

## Canon shapes

- **Little Chimera:** tiny quadruped, huge round head, short body, fur collar,
  blush cheeks, smile, ram horns; Okhema mascot (Felys/Canis/Terrazard mix).
- **Dromas (大地兽):** cute soft Georios earth-beast — round blunt head,
  soft eyes, white petal ruff (not spikes), smooth dusty periwinkle hide
  with almost no small scales, cream throat with few large rounded plates;
  ridden in Okhema (NOT clay-brown — earth-tone dyes are cosmetics).
- **Civilian:** white chiton, gold border, sandals — not a Heir.
- **Shrine:** marble stele + Greek pediment, not a torii.
